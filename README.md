## Kit Layout

Each kit folder contains exactly four user-facing files:

```text
STEP1_Drop_me_to_any_AI.md
STEP2_Fill_your_wallet_info.json
{project}_auto.py
If_you_dont_use_AI_read_me.txt
```

Do not add private keys or seed phrases to any kit config file.

## How to Use a Kit

1. Open [@WaterkoofAI_Bot](https://t.me/WaterkoofAI_Bot).
2. Use `/kithub` to browse available kits.
3. Use `/download [project name]` to unlock a kit with points.
4. Follow `STEP1_Drop_me_to_any_AI.md` for AI-guided setup, or `If_you_dont_use_AI_read_me.txt` for manual setup.
5. Install Bitget Wallet in the Chrome debug profile and run the kit script.

## How to Earn Points

- `/invite` - +30 pts per friend you invite
- `/rate` - +3 pts per kit rating (max 3/day)
- `/submit` - +150 to +400 pts for approved kits
